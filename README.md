# Quotation Generator for Sri Tech Computers

This project is a quotation generator application developed for Sri Tech Computers. It allows users to create, manage, and share price quotations for computer products and services.

## Features

- Generate professional quotations for computer products and services
- Save and manage customer quotations
- Export quotations in shareable formats
- User-friendly interface for quick quotation creation
- Unique order ID generation with timestamp prefixes (ST + date format)
- Customer information management (name, contact, address)
- Budget tracking and advanced payment recording
- Draft quotation system with price calculation
- Quotation status tracking (draft, completed)
- Order action management (mark as complete, edit, delete)
- Navigation menu with quick access to all features
- Search functionality for existing quotations
- Stock management with inventory tracking
- Product categorization system
- Cloud database integration for data synchronization
- Detailed order history and record keeping


## Technology Stack

- **Frontend**: React Native/TypeScript
- **State Management**: Zustand
- **Backend Integration**: Firebase
- **Animation**: Custom animations for enhanced UX


## Project Structure

The repository is organized into the following main directories:

- `/animations` - Custom animation components
- `/assets` - Static resources like images and fonts
- `/components` - Reusable UI components
- `/constants` - Application constants and configuration
- `/data` - Data models and mock data
- `/firebase` - Firebase configuration and services
- `/hooks` - Custom React hooks
- `/interfaces` - TypeScript interfaces
- `/screens` - Application screens/pages
- `/templates` - Quotation templates
- `/types` - TypeScript type definitions
- `/zustand` - State management with Zustand


## Installation

```bash
# Clone the repository
git clone https://github.com/Dinujaya-Sandaruwan/Qoutation-Generator-For-Sri-Tech-Computers.git

# Navigate to the project directory
cd Qoutation-Generator-For-Sri-Tech-Computers

# Install dependencies
pnpm install

# Start the development server
pnpm start
```


## Usage

1. Launch the application
2. Create a new quotation
3. Add products and services with pricing
4. Generate and save the quotation
5. Share with customers via preferred method
